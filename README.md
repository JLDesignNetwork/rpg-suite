## Core Capabilities

1. 🎲 **Inline Dice Evaluation:** Type or highlight dice math (`2d8+3`, `4d6kh3`, `/roll 1d20 advantage`) and calculate outcomes directly in the text editor.
2. 🧙 **Pre-Rolled Character Sheets:** Instantly generate complete multi-column character sheets for 6 major TTRPG systems.
3. ⚔️ **NPC & Monster Stat Blocks:** Generate formatted stat blocks with pre-calculated ability modifiers and skills.
4. ⏱️ **Encounter Tracker:** Generate interactive initiative tracking grids directly into your session notes.
