# JLDN RPG Suite — Usage & Command Palette Guide

> **Document:** `docs/usage.md`  
> **Author:** Jeff Langdon (JL Design Network)  

---

## 1. Installation

Install via Pulsar Package Manager (PPM):

```bash
ppm install rpg-suite
```

---

## 2. Command Palette Triggers (`cmd-shift-p` / `ctrl-shift-p`)

| Command | Action |
| :--- | :--- |
| `rpg-suite:roll` | Evaluates selected dice notation (e.g. `2d8+3`) in the active editor buffer. |
| `rpg-suite:gen-sheet-dnd5e` | Inserts a complete multi-column D&D 5e Character Sheet. |
| `rpg-suite:gen-sheet-cyberpunk` | Inserts a Cyberpunk Red Character Sheet. |
| `rpg-suite:gen-npc-dnd5e` | Inserts a pre-rolled D&D 5e NPC Stat Block. |
| `rpg-suite:gen-tracker` | Inserts an interactive Initiative & Encounter Tracker grid. |
